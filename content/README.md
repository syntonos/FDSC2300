# Content

All visible class content is Markdown. `pages/` contains page copy and external link settings, `dishes/<year>/` contains dish projects, `notes/` contains class notes, and `settings/site.md` contains shared course information. This README is documentation and is not rendered as a page.

Copy starters from the root `templates/` directory. See the root README for fields, image organization, and student galleries. New dishes and notes appear automatically; filenames determine their URLs. Dates determine dish year grouping, and `category` determines category filtering.
