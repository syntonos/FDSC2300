# Image organization

- `brand/`: Cornell's existing identity artwork.
- `pages/home/`: About-section photography.
- `dishes/<category>/<dish>/cover.jpg`: Food-only dish covers.
- `student-work/<year>/<dish>/`: Credited student photographs.
- `notes/<topic>/`: Images used in Markdown class notes.
- `library/`: Reusable reference photography.

Reference files with `/images/...` URLs in Markdown. Put student/team credits and captions in a dish's `gallery` frontmatter, and write descriptive alt text. Preserve original credits and publish only photographs you have permission to use. Current sources are recorded in `public/IMAGE-CREDITS.md` and `public/BRAND-CREDITS.md`.
