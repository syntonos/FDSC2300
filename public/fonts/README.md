# Locally hosted fonts

Cormorant Garamond (roman and italic) and DM Sans are open source variable fonts from the official Google Fonts repository. The font files are converted from the official TTF distributions to WOFF2 without modifying glyph outlines. Both families are distributed under the SIL Open Font License; license files are included alongside the fonts.

- https://github.com/google/fonts/tree/main/ofl/cormorantgaramond
- https://github.com/google/fonts/tree/main/ofl/dmsans

Use `font-weight: 300 700` for Cormorant Garamond and `font-weight: 100 1000` for DM Sans.
